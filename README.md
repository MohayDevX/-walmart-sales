# Walmart Sales Analysis

### Overview
A training project analyzing Walmart sales data using Python and Power BI.

### Key Numbers from Dashboard
- *Total Sales:* 2Bn
- *Total Records:* 1.755K (Count of Unemployment)
- *Holiday Flags:* 90
- *Period:* 2010 - 2012
- *Analysis:* Sum of Weekly Sales by Store & Unemployment Impact

### Tools Used
- Python: Pandas, NumPy, Matplotlib
- Power BI: Dashboard & Data Visualization
